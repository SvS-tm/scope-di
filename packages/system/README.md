# @svs-tm/system

Shared runtime and type utilities used by the Scope DI packages.

This package provides small helpers used internally by:

- `@svs-tm/scope-di`
- `@svs-tm/react-scope-di`

It is published separately to keep shared utilities versioned and reusable across the Scope DI ecosystem.

## Installation

```sh
npm install @svs-tm/system
```

Most users do not need to install this package directly.
